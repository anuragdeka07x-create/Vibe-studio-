# 🎵 VIBE Studio

A modern video and audio media studio application built with Kotlin and Jetpack Compose.

---

### 🚀 Features in Current Build (M1)
- **Import Media**: Open the native Android media picker to select video files.
- **Looping Video Playback**: Integrated hardware-accelerated playback with Media3 ExoPlayer (`REPEAT_MODE_ONE`).
- **Edge-to-Edge Material 3 UI**: Clean dark studio design built with Jetpack Compose.
- **Granular Storage Permissions**: Android 13+ `READ_MEDIA_VIDEO` / `READ_MEDIA_IMAGES` and legacy storage support.

---

### 🛠️ Installing on Android
1. Download the `VIBE-Studio.apk` from the link above.
2. Tap the downloaded file in your browser downloads or Files app.
3. If prompted with *"For your security, your phone is not allowed to install unknown apps from this source"*, tap **Settings** and toggle **Allow from this source**.
4. Tap **Install** and open VIBE Studio!
